# スキルツリーシステム

ANVILのスキルツリーは、Path of Exileにインスパイアされた深いビルドカスタマイズシステムです。
ツールを使用してレベルアップし、獲得したスキルポイントでスキルを習得できます。

## レベリング

### 経験値の獲得
ツールを使用することで経験値を獲得します。

| アクション | 獲得経験値 |
|----------|-----------|
| ブロック破壊 | 1-5 |
| モブ撃破 | 5-20 |
| クラフト | 2 |
| 釣り成功 | 3-10 |

### レベルアップ
- 最大レベル: **10,000**
- レベルアップごとに **1スキルポイント** 獲得
- 特定レベルでボーナスポイント獲得

## スキルツリーの構造

### ノードタイプ

| タイプ | 説明 | コスト |
|-------|------|-------|
| 小ノード | 小さなボーナス | 1ポイント |
| 中ノード | 中程度のボーナス | 3ポイント |
| 大ノード | 大きなボーナス | 5ポイント |
| キーストーン | 強力な効果（デメリットあり） | 10ポイント |

### スキルカテゴリ

**攻撃系**
- 攻撃力アップ
- クリティカル率アップ
- クリティカルダメージアップ

**採掘系**
- 採掘速度アップ
- 範囲採掘
- 幸運効果

**耐久系**
- 耐久値アップ
- 耐久消費軽減
- 自動修復

**特殊系**
- 経験値ボーナス
- ドロップ率アップ
- 特殊効果発動

## ジュエルシステム

スキルツリーには**ジュエルソケット**があり、
ジュエルを装着することで追加効果を得られます。

### ジュエルの入手
- モンスタードロップ
- 宝箱から発見
- クラフト

### ジュエルの種類
| ジュエル | 効果 |
|---------|------|
| ルビー | 攻撃力+5% |
| サファイア | 採掘速度+10% |
| エメラルド | 経験値+15% |
| ダイヤモンド | 全ステータス+3% |

## リスペック

**リスペックステーション**でスキルポイントをリセットできます。

### リスペックアイテム
| アイテム | 効果 |
|---------|------|
| リスペックオーブ | 1ポイントリセット |
| 完全リスペック | 全ポイントリセット |
