# Stations

ANVIL provides various crafting stations for tool creation and customization.

## Available Stations

### [Part Forge](part-forge.md)
A station for forging tool parts from vanilla materials.
Insert materials like iron ingots, gold ingots, or diamonds to create parts with random grades.

### [Tool Station](tool-station.md)
A station for combining forged parts to create custom tools.
Place the required parts for each tool type to assemble your tools.

## Station Overview

| Station | Purpose |
|---------|---------|
| Part Forge | Create tool parts from materials |
| Tool Station | Assemble parts into tools |
| Grade Station | Upgrade part grades |
| Core Box Station | Place modules on tools |
| Skill Tree Station | Manage skill points |
